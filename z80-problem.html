What Does This Z-80 Code Do?
2026-05-16

I was reviewing a printout of some firmware I wrote many years ago. I found a subroutine that was called a few times.

The firmware controlled an electronic device attached to a Kluge sheet-fed foil stamping press. It had various outputs like LEDs and stepper motor controllers, and various inputs like toggle switches, optical sensors, buttons, thumbwheel switches, and limit switches.

The code ran on a Z-80 compatible processor (Hitachi HD64180). On the Z-80, most registers are 8 bits and most ALU operations involve the A register, the accumulator. For purposes of this exercise I modified the original code, including making it compatible with the original 8080. The routine uses three 8-bit registers.

  • A holds the input argument at entry and the result at the end.
  • B and C are used as scratch storage and overwritten.
F1 LD B,A ; B <- A AND F0H ; CLEAR LOW 4 BITS OF A RRCA ; ROTATE RIGHT A RRCA ; ROTATE RIGHT A LD C,A ; C <- A CPL A ; A <- ~A (ONES' COMPLEMENT) RRCA ; ROTATE RIGHT A ADD A,B ; A <- A + B SUB A,C ; A <- A - C INC A ; A <- A + 1 RET ; RETURN RESULT IN A
The RRCA instruction moves the low bit of A to the high bit, and shifts the other 7 bits right. Thus, 8 RRCA instructions will set the A register back to its initial value. Other instructions are explained in the comments.
